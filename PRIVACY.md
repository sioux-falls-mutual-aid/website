# Please do not put people's private lives on GitHub

This repository is **public**.

That means an issue, comment, screenshot, commit, or file can be copied, indexed, shared, or preserved somewhere long after we wish it hadn't been.

So we're going to be a little fussy about privacy.

## Please never post

Do not put any of this into the repo about somebody seeking help:

- their name;
- home address or current safe location;
- personal phone number or email;
- medical or mental-health information;
- immigration status or documents;
- details about abuse, stalking, sexual violence, or family safety;
- identifying information about children;
- bank/account information;
- Social Security numbers, IDs, or documents;
- private messages or screenshots with identifying information.

Also do not publish private organizer phone numbers, confidential shelter locations, or private Signal/Discord/group-chat links.

## This is not where people ask for mutual aid

GitHub is a maintenance tool. It is not a safe intake form.

If you need food, rent help, transportation, shelter, medical help, or other support, use the SFMA website:

https://www.siouxfallsmutualaid.org/

## Public resource information is fine

We *do* want public information about services, such as:

- an organization's public phone number;
- a public office address;
- published hours;
- eligibility rules;
- official links;
- fares or fees;
- public service-area information;
- publicly announced program changes.

The rule is basically:

**Information about the service: yes.  
Information about the person using the service: no.**

## Tell us about the problem, not the person

Good:

> The shelter listing doesn't explain whether people outside Minnehaha County can use the service.

Not good:

> [Name] from [address] called and said they were turned away.

We can fix the first problem without exposing the second person's life to the internet.

## Safety-sensitive resources

Domestic-violence shelters, safe houses, immigration-defense work, and similar resources sometimes keep locations or operational details private for a reason.

If an organization does not intentionally publish something for the public, neither should we.

Use their public phone number, hotline, website, or other public contact path instead.

## If something private gets posted by accident

Do not quote it into another comment. Do not copy it into a "cleanup" issue.

Tell a repository admin as quickly as possible so we can remove or redact it.

Git history and outside indexing can make cleanup imperfect, which is why we'd much rather prevent the problem in the first place.
