Quick exit

Leaves this page right away, and so does pressing Escape twice on a keyboard. It cannot erase your history, so if someone checks this device, use one they cannot reach.

Quick Exit demo

This is a real working demo. Clicking Quick exit or pressing Escape twice quickly will leave this page for the National Weather Service.

Important: Quick Exit replaces this current page in browser history. It does not erase browsing history or earlier pages you may already have visited on the same site.

Focus the field above and press Escape twice. The exit should not fire while you are typing.
