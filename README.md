# Sioux Falls Mutual Aid — Website & Resource Directory

This is where we keep track of the slightly ridiculous amount of work that goes into keeping the [Sioux Falls Mutual Aid website](https://www.siouxfallsmutualaid.org/) useful, accurate, and actually usable by people who need it.

It is part website workshop, part resource-maintenance desk, and part giant collective to-do list.

## Need help right now?

**Please don't ask for mutual aid here.**

GitHub is extremely public and extremely bad at keeping secrets. If you need food, rent help, a ride, somewhere safe to go, medical help, or other direct support, head to the actual SFMA website:

https://www.siouxfallsmutualaid.org/

Please do **not** put your name, address, phone number, medical information, immigration information, abuse/survivor information, or other private details into a GitHub issue.

## What *does* belong here?

Things like:

- "This pantry changed its Tuesday hours."
- "That phone number doesn't work anymore."
- "This page is awful on a phone."
- "I think this resource only serves Minnehaha County."
- "We should have a page for Clay County."
- "This button is hard to use with a keyboard."
- "This wording makes absolutely no sense if you're panicking."
- "I found a resource we should look into."

Basically: if it helps us make the public website more accurate, useful, understandable, or easier to maintain, it probably belongs here.

## How we're building this

One of our big rules is:

**One resource. One record. Update it once.**

We do not want the same phone number copied onto five different pages and quietly becoming wrong in four of them.

Each public service or resource should have one canonical record. The website can then show that same information wherever it is useful: Food, Housing, Help Right Now, Vermillion, statewide resources, etc.

## How the board works

Our project board moves work through:

**Backlog → In progress → Needs verification → In review → Ready to publish → Done**

- **Backlog:** Yep, we need to do this. No, nobody is doing it yet.
- **In progress:** Somebody is actively working on it.
- **Needs verification:** We have information, but something important still needs to be confirmed.
- **In review:** The facts are settled. Now we're checking whether the finished thing is clear, usable, accessible, and not weird.
- **Ready to publish:** Good to go; it just needs to be put live.
- **Done:** It is finished, fixed, or published.

## A note about crisis resources

Someone trying to find a food pantry next week has different needs than someone trying to find somewhere safe to sleep tonight.

So **Help Right Now** is being designed as its own fast path: fewer choices, obvious phone/text actions, honest answers about what is and isn't available locally, and regional/statewide options when a town simply does not have the service someone needs.

We do not want someone in crisis doing detective work on our website.

## Want to help?

Read [CONTRIBUTING.md](CONTRIBUTING.md).

You absolutely do not need to be a programmer. Useful contributions include checking official sources, calling organizations to verify information, researching rural services, testing pages on a phone, finding accessibility problems, improving wording, and — yes — writing code.

Before posting anything about another person, please read [PRIVACY.md](PRIVACY.md).

## One last privacy rule

This repo can contain **public information about organizations and services**.

It should never contain private information about people asking for help, private organizer coordination, confidential shelter locations, private group links, or anything else that would make somebody less safe if it were public.

When in doubt, describe the problem without describing the person.
